# Contributing to Doomscroll Siren

Thank you for your interest in contributing to **Doomscroll Siren**!

## Development Setup

```bash
git clone https://github.com/<your-username>/doomscroll-siren.git
cd doomscroll-siren
npm install
npm run dev
```

## Verification Checks

Before opening a pull request, run:

```bash
npm run lint
npm run build
```

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
